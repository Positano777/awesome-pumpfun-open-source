# Crypto tools worth evaluating next

Checked 2026-10-22. Research hypotheses; no candidate execution or security audit performed. Issue states can change.

| Priority | Small useful contribution | Existing foundation | Evidence and limits |
|---|---|---|---|
| 1 | **Route Availability Doctor:** timestamped ROUTABLE / NO_ROUTE / UNKNOWN quote report, cache age and sanitized errors; no signing | [LI.FI SDK](https://github.com/lifinance/sdk), [Apache-2.0](https://raw.githubusercontent.com/lifinance/sdk/main/LICENSE) | [Open #502, 2026-09-30](https://github.com/lifinance/sdk/issues/502): token discovery does not establish amount/pair routing. Test with integration developers; API limits apply. |
| 2 | **Exchange CSV Import Audit:** original row numbers, unsupported types, explicit timezone, per-account duplicate candidates, exact totals | Contribute fixtures/adapters to [Rotki](https://github.com/rotki/rotki), [AGPL v3](https://github.com/rotki/rotki/blob/develop/LICENSE.md); independently authored companion is another option | [Crypto.com #12499](https://github.com/rotki/rotki/issues/12499) and [timezone #12143](https://github.com/rotki/rotki/issues/12143) are fixed. [Ghostfolio #7728](https://github.com/ghostfolio/ghostfolio/issues/7728) is open but its example is not crypto. No tax claims. |
| 3 | **EVM Data Health Receipt:** bounded explorer/RPC comparison, block hashes, pagination, request limits and unknown coverage | Original client; evaluate [TrueBlocks](https://github.com/TrueBlocks/trueblocks-core), [GPL v3](https://github.com/TrueBlocks/trueblocks-core/blob/develop/LICENSE) | [Blockscout #14869](https://github.com/blockscout/blockscout/issues/14869) is closed; [#14857](https://github.com/blockscout/blockscout/issues/14857) open. Current [Blockscout license](https://raw.githubusercontent.com/blockscout/blockscout/master/LICENSE) is custom; RPC/history access can cost money. |
| 4 | **Stablecoin Payout Receipt Matcher:** offline exact intent-to-receipt matching for one chain/token; duplicate and ambiguous reports | Evaluate [x402-recon](https://pypi.org/project/x402-recon/) first; MIT is package metadata, source/license audit incomplete | [Need signal](https://www.reddit.com/r/StableCoins/comments/1r27twd/reconciliation_on_stablecoin_payments/) is secondhand and exact date unverified. Weak demand evidence; no sending or tax reporting. |
| 5 | **Permission Provenance Fixtures:** distinguish standing permissions, one-time signatures, and unknown trace evidence | Upstream contribution to [RevokeCash](https://github.com/RevokeCash/revoke.cash), [MIT-style license](https://github.com/RevokeCash/revoke.cash/blob/master/LICENSE) | [2026-08 review and response](https://forum.arbitrum.foundation/t/final-report-revoke-cash/31239) reflect semantic disagreement, not confirmed vulnerability. Existing history already shipped; avoid a duplicate approval dashboard. |

Additional licensing caution: [Safe transaction-service](https://raw.githubusercontent.com/safe-global/safe-transaction-service/main/LICENSE) preserves historical MIT code through 2026-02-16 but uses FSL-1.1-MIT for newer code, with a competing-use restriction. [Ghostfolio](https://raw.githubusercontent.com/ghostfolio/ghostfolio/main/LICENSE) is AGPL v3. Check exact components and commits before copying code. Open code does not guarantee free hosted APIs or historical data.
