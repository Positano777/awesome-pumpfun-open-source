## Specialized-tool series

Publish one useful explanation at a time. Link the exact upstream project, say what it does, identify the license and costs, and show a small reproducible example before calling an integration shipped.

1. LiteSVM: local transaction simulation and pinned account fixtures. Simulation isn’t a guarantee of mainnet execution.
2. Trident: reusable fuzzing harnesses for program invariants. A fuzzing framework is not an audit.
3. Solana Kit: modular transaction and RPC primitives; document version compatibility.
4. Umi: metadata inspection and plugin-based clients; distinguish mutable metadata from malicious intent.
5. Helius SDK: optional managed-provider feeds; open SDK does not mean free hosted APIs.
6. Treasury tooling: explain Squads proposal flows only after clarifying component licensing.

Source links and license evidence live in SPECIALIZED.md in the catalog. Orca, Codama license-text confirmation, Squads component scope, and Solana Verify license evidence retain explicit holds.
