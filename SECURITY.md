# Security and catalog scope

This repository is a source-backed catalog, not an endorsement or audit of listed software. Do not run unknown code, import a funded wallet into an unreviewed bot, or infer reuse rights from public visibility alone.

Never submit API keys, private keypairs, wallet recovery phrases, or credential-bearing URLs in issues or PRs. Run `gitleaks git --redact=100 --log-opts="--all" .` with the checked-in default-extended rules before release. Review matches without publishing their values.

The launch-evidence credential review is available in [the toolbox](https://github.com/Positano777/pumpfun-community-tools/blob/main/docs/SECURITY_REVIEW.md). Secret scanning is not proof of absence or a complete application audit. A real exposed credential must be revoked/rotated with its provider before history cleanup.
