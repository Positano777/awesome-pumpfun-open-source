# Contributing

Submit an issue or pull request with the exact owner/repository URL, category, LICENSE link, implementation entry points, review date, and known limits. State whether you are the author or otherwise affiliated. Mark unknown fields explicitly. Do not describe same-slot correlation as proof of shared ownership.

Update data/repositories.csv, run `python scripts/build_data.py`, then run `python scripts/check_catalog.py`. Update the README and REVIEW.md when a recommendation changes. Submissions of original catalog text/data are CC0-1.0; third-party code retains its license. Never submit credentials, private keys, or binaries.
