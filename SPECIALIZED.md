# Specialized Solana foundations — checked 2026-10-21

## Which tools solve useful problems without duplicating upstream engines?

### Takeaway
Prioritize reusable simulation, decoding, metadata inspection, and treasury transparency. The actions below are adaptation proposals, not claims that Positano777 authored upstream tools. Eight practical candidates plus two reference/hold cases are recorded in the companion CSV.

### Cited Findings
- **LiteSVM** provides an in-process Solana VM, program loading, simulation, account fixtures, and slot/time manipulation. Source includes simulation/send examples and compute-unit assertions. Apache-2.0 text inspected; release v0.18.1 includes mainnet feature-set and invalid-data fixes. [Source](https://github.com/LiteSVM/litesvm/blob/master/crates/litesvm/src/lib.rs) · [License](https://github.com/LiteSVM/litesvm/blob/master/LICENSE) · [Releases](https://github.com/LiteSVM/litesvm/releases)
- **Trident** is a Rust Solana fuzzing framework. Its MIT license is explicit; release history documents invariant, error-reporting, and SVM changes, including prereleases. [Source](https://github.com/Ackee-Blockchain/trident) · [License](https://github.com/Ackee-Blockchain/trident/blob/master/LICENSE) · [Releases](https://github.com/Ackee-Blockchain/trident/releases)
- **Kit**, at `anza-xyz/kit`, is the successor to web3.js 2.x, with modular RPC, codec, and transaction primitives and browser-wallet examples. MIT license inspected; v8.5.0 dated 2026-10-13. [Source](https://github.com/anza-xyz/kit) · [License](https://github.com/anza-xyz/kit/blob/main/LICENSE) · [Releases](https://github.com/anza-xyz/kit/releases)
- **Umi** is a JavaScript client framework; release notes include uploader plugins, account helpers, and Kit adapters. MIT license inspected; visible v1.6.0 release. [Source](https://github.com/metaplex-foundation/umi) · [License](https://github.com/metaplex-foundation/umi/blob/main/LICENSE) · [Releases](https://github.com/metaplex-foundation/umi/releases)
- **Codama** standardizes program IDLs and generates clients, documentation, and parser tooling through visitors/renderers. GitHub reports MIT; the LICENSE body could not be retrieved in this pass. Default branch is `1.x`; release codama@1.11.0 is visible. [Source](https://github.com/codama-idl/codama) · [README](https://github.com/codama-idl/codama/blob/1.x/README.md) · [Releases](https://github.com/codama-idl/codama/releases)
- **Helius SDK** is MIT-licensed client software for managed Helius APIs. v3.3.0 adds Parsed Events/Streams and documents changed subscription error handling. README also includes signing/payment helpers; LaserStream is a separate package. [README](https://github.com/helius-labs/helius-sdk/blob/main/README.md) · [License](https://github.com/helius-labs/helius-sdk/blob/main/LICENSE) · [Releases](https://github.com/helius-labs/helius-sdk/releases)
- **Wallet Adapter** offers modular TypeScript wallet components under Apache-2.0. Release history shows wallet packages and a signature-verification example update. [Source](https://github.com/anza-xyz/wallet-adapter) · [License](https://github.com/anza-xyz/wallet-adapter/blob/master/LICENSE) · [Releases](https://github.com/anza-xyz/wallet-adapter/releases)
- **Squads v4** includes multisig program and TS/Rust clients, with time locks, roles, spending limits and vaults. Root LICENSE is AGPL-3.0 while the TS SDK manifest declares MIT: component scope needs confirmation. [README](https://github.com/Squads-Protocol/v4/blob/main/README.md) · [Root license](https://github.com/Squads-Protocol/v4/blob/main/LICENSE) · [SDK manifest](https://github.com/Squads-Protocol/v4/blob/main/sdk/multisig/package.json)
- **Solana Verify** compares reproducible program builds with deployed executables; former Ellipsis-Labs URL redirects to Solana Foundation. Cargo manifest declares MIT, but an accompanying root LICENSE was not found in the inspected tree. [Source](https://github.com/solana-foundation/solana-verifiable-build) · [Manifest](https://github.com/solana-foundation/solana-verifiable-build/blob/master/Cargo.toml)
- **Orca Whirlpools** has TS/Rust clients and quote/math packages. Despite its open-source description, current root LICENSE replaced Apache-2.0 on 2025-02-27 with non-commercial and competitor restrictions. Keep it outside the freely reusable shortlist pending package-specific clarification. [README](https://github.com/orca-so/whirlpools/blob/main/README.md) · [License](https://github.com/orca-so/whirlpools/blob/main/LICENSE)

### Inferences
- **Best next small product: Transaction Lab.** Depend on LiteSVM and Kit for reproducible simulation fixtures and plain-language balance, authority, and instruction explanations. Publish fixtures and limitations rather than a claim that simulation guarantees execution.
- **Metadata Doctor:** Umi-based inspection of token metadata, broken URIs, inconsistent JSON, and mutable update authority. Keep fetching read-only and distinguish unavailable content from fraud.
- **IDL Drift Watch:** Codama-based comparisons of versioned IDLs and generated decoder fixtures. This supports the current evidence exporter and gives other developers a concrete reusable asset.
- **Treasury Glass:** a read-only Squads proposal/vault activity viewer, with component licensing resolved before reuse. Useful for documenting community funding, not a reason to create a new treasury now.
- **Watchtower adapters:** offer Helius as an optional managed provider alongside open streaming infrastructure; explain API credentials and hosting costs. Avoid copying signup/payment helpers into alert examples.
- **Fuzz Recipes:** publish Trident harnesses for programs the community actually develops. A tutorial/harness collection is more useful than an unchanged framework fork.
- Prefer dependencies, demonstrations, upstream links, and upstream contributions. None of these findings justifies mass-forking mature frameworks.

### Gaps
- This is source/documentation and license triage, not an audit or runtime compatibility test. No dependency was installed, no signing key supplied, no trades sent, and no repository published.
- Full source review, pinned commit/license capture, dependency audits, and mainnet compatibility checks remain before adoption. Codama license-body retrieval, Squads component licensing, and Solana Verify license-text completeness need follow-up.
- Maintenance evidence is release-page/source observation, not an SLA or promise of future support. Stars are deliberately not used as proof of quality.
